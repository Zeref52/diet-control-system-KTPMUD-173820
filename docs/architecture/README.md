# Biểu đồ kiến trúc hệ thống

Thư mục chứa các biểu đồ kiến trúc dưới dạng ảnh PNG và file nguồn PlantUML.

## Danh sách biểu đồ

| File | Loại | Mô tả |
|------|------|-------|
| `c4-c1-context.png/.puml` | C4 Mức 1 | System Context - Ranh giới hệ thống |
| `c4-c2-container.png/.puml` | C4 Mức 2 | Container - Web, Mobile, API, DB |
| `dfd-level-0.png/.puml` | DFD | Context Diagram - Luồng dữ liệu mức 0 |
| `dfd-level-1.png/.puml` | DFD | Level 1 - Phân rã tiến trình |
| `use-case-diagram.png/.puml` | UML | Biểu đồ Use Case tổng thể |
| `class-diagram.png/.puml` | UML | Biểu đồ lớp |
| `sequence-diagram-1.png/.puml` | UML | Sequence ghi chép bữa ăn |
| `sequence-diagram-2.png/.puml` | UML | Sequence xuất báo cáo |
| `activity-diagram-1.png/.puml` | UML | Activity ghi chép bữa ăn |
| `activity-diagram-2.png/.puml` | UML | Activity xuất báo cáo |
| `erd-diagram.png` | ERD | Sơ đồ thực thể liên kết |

## Công cụ vẽ

- **PlantUML** (https://plantuml.com/) - dùng file `.puml`
- **Draw.io** (https://app.diagrams.net/) - export PNG và file `.drawio`
