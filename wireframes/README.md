# Wireframe/Mockup giao diện

Thư mục chứa wireframe/Mockup cho các màn hình chính của hệ thống.

## Danh sách màn hình

| File | Màn hình | Mô tả |
|------|----------|-------|
| `login.png` | Đăng nhập/Đăng ký | Form đăng nhập với logo, link đăng ký |
| `dashboard.png` | Trang chủ | Thanh tiến độ calo, danh sách bữa ăn hôm nay |
| `meal-log.png` | Ghi chép bữa ăn | Tìm kiếm món, nhập khối lượng, thêm vào bữa |
